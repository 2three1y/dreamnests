                What works here, honestly

                Listen-only, right here

                • Live streams that publish a public HLS stream (a link ending in .m3u8) play in this page, audio only. That covers zap.stream, Shosho and most Nostr radio streams.
                • Safari and every browser on iPhone play these natively. Chrome on Android or a computer may not, and then the button opens the stream's own page instead.

                Opens the room's own app

                • Nests rooms stream with a newer technology (Media over QUIC) that only the Nests app can play, so Listen opens the room on nostrnests.com.
                • Corny Chat and HiveTalk rooms open on their own sites too.

                Full speaking

                • Talking, raising your own hand and posting chat need the room's own app and a Nostr login. Dream Nests is read-only: no login, no keys, nothing posted.

                Earcons

                • Hand raised: from Nests presence events, when someone's hand goes up.
                • Mic on: from Nests presence events, when a speaker unmutes. This is not true voice detection, which only the Nests app can hear.
                • Room ended: when the room's event changes to ended.
                • Corny Chat and live streams don't publish hand or mic events, so only room ended and chat work there.

                Safety

                • Rooms and messages marked sensitive, NSFW or adult are hidden by default, including ones that only say NSFW in the title.
                • Links and images in chat are shown as plain text, never loaded.

                Keyboard

                • Every control is a normal link or button. Use Tab, Enter and Space, or your screen reader's heading and link navigation.
                • Each room in the list is a heading, so you can jump room to room by heading.
                • Escape goes back to the room list from inside a room.
